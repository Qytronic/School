## 📂 Branches & How to Navigate

To keep the repository clean, organized, and easy to grade, **each informatics topic lives in its own Git branch**. The `main` branch serves purely as the documentation hub.

### 🏷️ Available Branches

* 🏠 [**`main`**](../../tree/main) – Documentation, license, `.gitignore`, and general repository setup.
* 🎨 [**`Farben-und-Strichdicke`**](../../tree/Farben-und-Strichdicke) – Python graphics and drawing exercises focusing on colors, line thickness, and visual outputs.
* *(More branches will be added as the school year progresses)*
