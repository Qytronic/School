## 📂 Branches & How to Navigate

To keep the code clean and organized, **each topic or exercise set lives in its own Git branch**. The `main` branch serves as the documentation hub and homepage for the repository.

### 🏷️ List of Branches

* 🏠 [**`main`**](../../tree/main) – Documentation, license, `.gitignore`, and general repository setup.
* 🎨 [**`Farben-und-Strichdicke`**](../../tree/Farben-und-Strichdicke) – Python graphics and drawing exercises focusing on colors, line thickness, and visual outputs.
* *(More branches will be added here as new topics are covered in class)*

### 💡 How to switch and inspect branches:

#### Option 1: Directly on GitHub (Web)
1. Go to the top left of the repository file list.
2. Click on the branch selection dropdown (it currently says `main`).
3. Select the branch you want to inspect (e.g., `Farben-und-Strichdicke`).

#### Option 2: In Visual Studio Code / Terminal
If you clone or pull the repository locally, switch branches using Git commands:

```bash
# Fetch all remote branches from GitHub
git fetch --all

# Switch to a specific topic branch
git checkout <branch-name>

# Example:
git checkout Farben-und-Strichdicke
